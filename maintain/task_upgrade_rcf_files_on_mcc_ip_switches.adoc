= Upgrade RCF files on MetroCluster IP switches
:icons: font
:imagesdir: ../media/

[.lead]
You might need to upgrade a reference configuration file (RCF) on a MetroCluster IP switch. For example, if the RCF version that you are running on the switches is not supported by the ONTAP version, the switch firmware version, or both.

.Before you begin

* If you are installing new switch firmware, you must install the switch firmware before upgrading the RCF.
* Before you upgrade the RCF, link:task_upgrade_firmware_on_mcc_ip_switches.html[verify that the RCF is supported].
* link:enable-console-logging-before-maintenance.html[Enable console logging] before performing this task.

.About this task

* This procedure disrupts traffic on the switch where the RCF is upgraded. Traffic resumes when the new RCF is applied.

* Perform the steps on one switch at a time, in the following order: Switch_A_1, Switch_B_1, Switch_A_2, Switch_B_2.

// 2024 Aug 13, ONTAPDOC-1988

.Steps 

. Verify the health of the configuration.
.. Verify that the MetroCluster components are healthy:
+
`metrocluster check run`
+
----
cluster_A::*> metrocluster check run

----

+
The operation runs in the background.

.. After the `metrocluster check run` operation completes, run `metrocluster check show` to view the results.
+
After approximately five minutes, the following results are displayed:
+
----
-----------
::*> metrocluster check show

------------------- ---------

config-replication  ok
aggregates          ok
clusters            ok
connections         ok
volumes             ok
7 entries were displayed.
----

.. Check the status of the running MetroCluster check operation:
+
`metrocluster operation history show -job-id 38`
.. Verify that there are no health alerts:
+
`system health alert show`

. If your MetroCluster IP configuration has NVMe shelves connected to the MetroCluster IP switches, run the following commands to verify the shelf status.

. link:../install-ip/switch-move-cluster-lifs.html[Move the cluster LIFs] before you begin the upgrade. 

. Prepare the IP switches for the application of the new RCFs.
+
Follow the steps for your switch vendor:
+
* link:../install-ip/task_switch_config_broadcom.html#resetting-the-broadcom-ip-switch-to-factory-defaults[Reset the Broadcom IP switch to factory defaults]
+
* link:../install-ip/task_switch_config_cisco.html#reset-the-cisco-ip-switch-to-factory-defaults[Reset the Cisco IP switch to factory defaults]
+
* link:../install-ip/task_switch_config_nvidia.html#reset-the-nvidia-ip-sn2100-switch-to-factory-defaults[Reset the NVIDIA IP SN2100 switch to factory defaults]

. Download and install the IP RCFs, depending on your switch vendor.
+
* link:../install-ip/task_switch_config_broadcom.html#downloading-and-installing-the-broadcom-rcf-files[Download and install the Broadcom IP RCFs]
+
* link:../install-ip/task_switch_config_cisco.html#download-and-install-the-cisco-ip-rcf-files[Download and install the Cisco IP RCFs]
+
* link:../install-ip/task_switch_config_nvidia.html#download-and-install-the-nvidia-rcf-files[Download and install the NVIDIA IP RCFs]
+
NOTE: If you have an L2 shared or L3 network configuration, you might need to adjust the ISL ports on the intermediate/customer switches. The switchport mode might change from 'access' to 'trunk' mode. Only proceed to upgrade the second switch pair (A_2, B_2) if the network connectivity between switches A_1 and B_1 is fully operational and the network is healthy.

. Repeat the previous steps for each of the switches.
+
NOTE: After you have configured the switches in the first fabric (Switch_A_1, Switch_B_1), you must repeat the steps to move the cluster LIFs on the second fabric (Switch_A_2, Switch_B_2). Refer to link:../install-ip/task_install_and_cable_the_mcc_components.html[Learn about configuring the MetroCluster IP switches].
