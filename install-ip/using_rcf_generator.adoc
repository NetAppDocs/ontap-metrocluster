= Learn about cabling the MetroCluster IP switches
:icons: font
:imagesdir: ../media/

[.lead]
Before you begin to cable the MetroCluster IP switches, review the requirements. 

.Before you begin

Review these considerations before cabling the switches:

* The same cabling is used for site A and site B.
* You cannot configure the switches with ports of different speeds (for example, a mix of 100 Gbps ports and 40 Gbps ports).
* Keep track of the MetroCluster port group (MetroCluster 1, MetroCluster 2, etc.). You'll need this information when using the RcfFileGenerator tool as described later in this configuration procedure.
* You should cable all of the nodes in the same way. If there are different port combination options available to cable the nodes, all nodes should use the same port combinations. For example, e1a on node1 and e1a on node2 should be attached to one switch. Similarly, the second port from both nodes should be attached to the second switch. 


NOTE: The reference configuration file (RCF) version is different to the version of the RCFfilegenerator tool used to generate the file. For example, you can generate an RCF version 2.00 using RCFfilegenerator v1.6c. 

== Cabling requirements based on the switch type

The following lists cabling requirements based on the specific switch type.

=== Cisco 3132Q-V

If you configure the switch for MetroCluster FC to IP transition, port 5 or port 6 can be used to connect the local cluster interfaces of the MetroCluster FC node. Refer to the link:https://mysupport.netapp.com/site/tools/tool-eula/rcffilegenerator[RcfFileGenerator for MetroCluster IP^] and the generated cabling files for more details on cabling this configuration.

=== Cisco 3232C or 36-port Cisco 9336C

* If you configure the switch for MetroCluster FC to IP transition, port 5, port 6, port 13, or port 14 can be used to connect the local cluster interfaces of the MetroCluster FC node. Refer to the link:https://mysupport.netapp.com/site/tools/tool-eula/rcffilegenerator[RcfFileGenerator for MetroCluster IP^] and the generated cabling files for more details on cabling this configuration.
* RCF version v2.10 or later is required for 25G breakout mode for MetroCluster ISLs on supported platforms.

* ONTAP 9.13.1 or later and RCF version 2.00 are required to use a platform other than FAS8200 or AFF A300 in the "MetroCluster 4" group.

=== 12-port Cisco 9336C-FX2

The 12-port Cisco 9336C-FX2 switch doesn't support connecting NS224 shelves to the MetroCluster switch.

=== 36-port Cisco 9336C-FX2 switch connecting NS224 storage

* Connecting one eight-node or two four-node MetroCluster configurations requires ONTAP 9.14.1 or later.

* When you cable a Cisco 9336C-FX2 switch connecting NS224 storage, you can only have a maximum of two MetroCluster configurations or DR groups. At least one MetroCluster configuration or DR group must be connecting NS224 shelves to the MetroCluster switch.

* The RcfFileGenerator only shows eligible platforms when the first platform is selected.

* If you are expanding a regular MetroCluster configuration that doesn't support switch-attached NS224 storage and you want to add a MetroCluster configuration that has switch-attached NS224 storage, review the following information:
+
In the RcfFileGenerator tool, you must select the platform that supports switch-attached NS224 storage first, then select the platform that doesn't support switch-attached NS224 storage.
+
This means that when you generate the RCF for your new configuration, you might need to select the platforms in the RcfFileGenerator tool in the following order:

. Select the platform that supports switch-attached NS224 storage from the second drop-down field.

. Select the platform that doesn't support switch-attached NS224 storage from the first drop-down field.

=== Broadcom BES-53248

* You cannot use the switches with remote ISL ports of different speeds (for example, a 25 Gbps port connected to a 10 Gbps ISL port).

 ** Transitioning from MetroCluster FC to MetroCluster IP configurations
 ** Refreshing a four-node MetroCluster IP configuration (ONTAP 9.8 and later)


=== NVIDIA SN2100

Connecting an eight-node or two four-node MetroCluster configurations requires ONTAP 9.14.1 or later and RCF version 2.00 or later.
