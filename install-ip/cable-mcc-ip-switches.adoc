= Cable your MetroCluster IP switches using the RCFfilegenerator tool and the Hardware Universe 
:icons: font
:imagesdir: ../media/

[.lead]
You must understand how to use the RCFfilegenerator tool and information in the NetApp Hardware Universe to correctly cable your switches.

.Before you begin

Review the information in link:using_rcf_generator.html[Learn about cabling the MetroCluster IP switches] before performing this task.

.Steps

. Download and install the https://mysupport.netapp.com/site/tools/tool-eula/rcffilegenerator[RcfFileGenerator for MetroCluster IP^] tool from the NetApp Support Site.

. Follow the steps in link:https://kb.netapp.com/on-prem/ontap/mc/MC-KBs/How_to_use_the_RCF_Generator_for_MetroCluster_IP[How to use the RCF Generator for MetroCluster IP^] to populate the fields for your configuration. 
+
The tool generates a per-port cabling overview for each switch.
+
NOTE:  The RcfFileGenerator only shows eligible platforms when the first platform is selected.

. Navigate to the link:https://hwu.netapp.com/DetailViews/Home.aspx[Hardware Universe^]
. Select your platform type from the *Products* tab, and then select your specific platform and whether you are cabling a four-node or eight-node MetroCluster IP configuration.
. Select the ONTAP version from the display window and then select *Show results*.
. Select *Supported connections* and select the tab for *Storage connection* 
. Gather the controller port information for your configuration.
+
NOTE: The controller port information is not included in the cabling overview generated by the RcfFileGenerator tool so you must use the Hardware Universe to collect this information.
