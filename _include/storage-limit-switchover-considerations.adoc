Beginning with ONTAP 9.20.1, storage limits can be configured for SVMs that are part of a MetroCluster IP configuration.

CAUTION: You must ensure that your MetroCluster configuration does not exceed the limits for your platform listed in the https://hwu.netapp.com/[Hardware Universe^].

* During normal operation (not in switchover), you can change the storage limit configuration only on the *sync-source SVM*. You cannot enable, disable, or modify storage limits on the *sync-destination SVM*.

* While in switchover, the following restrictions apply to the *sync-destination SVM*:

** You can't use the `vserver modify -storage-limit` command to enable or disable the storage limit on the sync-destination SVM. That is, you can't change the value from 0 to a non-zero value, or from a non-zero value to 0. The command fails with the following error:
+
`This operation is not permitted on a Vserver that is configured as the destination of a MetroCluster Vserver relationship`
** You can still change the storage limit from one non-zero value to another (for example, from 100TB to 200TB). This new value is retained across switchback.
** To enable or disable the storage limit, wait until switchback completes, then make the change on the *sync-source SVM*. The value is then replicated to the sync-destination SVM.


For more information, refer to link:https://docs.netapp.com/us-en/ontap/volumes/manage-svm-capacity.html[Manage ONTAP SVM capacity^]
